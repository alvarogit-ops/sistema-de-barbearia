1. Visão Geral & Acesso

O Barber Grid é uma plataforma moderna desenvolvida em Django que conecta clientes e barbeiros, simplificando o processo de agendamento de horários e gestão da barbearia.

Interface Adaptativa

O sistema adapta-se automaticamente ao tema do dispositivo (Claro/Escuro) e ajusta o layout perfeitamente para telas de celular, tablet ou computador.

Horários Dinâmicos

Bloqueio automático de horários que já passaram, feriados nacionais, intervalos de almoço e agendamentos conflitantes.

2. Guia do Cliente

Criando uma conta e fazendo login

1
Acesse a tela de Login

Navegue até a rota /login e clique em "Criar uma conta" se for seu primeiro acesso.

2
Preencha seus dados

Informe seu Nome Completo, Telefone de contato, E-mail válido e crie uma Senha segura.

Como realizar um agendamento

  1. Acesse a aba Agendar no menu principal.
  2. Escolha o serviço desejado (Corte, Barba, Combo, etc.).
  3. Selecione o dia desejado no calendário. Apenas dias válidos exibirão horários livres.
  4. Clique no horário disponível desejado.
  5. Adicione observações (opcional) e clique em Confirmar.
Atenção: O agendamento nascerá com o status Solicitado e passará para Confirmado após a aprovação do barbeiro.

Minhas Reservas & Cancelamentos

Na aba "Minhas reservas" você encontra duas abas principais:

  • Próximas: Exibe agendamentos futuros. Você pode clicar no item para ver detalhes ou solicitar o Cancelamento.
  • Histórico: Registros de atendimentos antigos já concluídos ou cancelados.

3. Guia do Administrador / Barbeiro

Acesso exclusivo para administradores da barbearia (usuário com privilégios de staff).

Agenda do Dia

No menu Agenda, o barbeiro visualiza todos os agendamentos do dia selecionado. É possível filtrar por data ou por status (Solicitado, Confirmado, Cancelado).

A Confirmar

Painel dedicado para aceitar ou recusar novas solicitações pendentes de clientes com apenas um clique.

Gestão de Serviços

Em Cadastros > Serviços, o barbeiro pode gerenciar o catálogo do estabelecimento:

  • Cadastrar Novo Serviço: Defina o Nome, Preço (R$), Duração estimada em minutos e faça upload de uma foto ilustrativa.
  • Status Ativo/Inativo: Desative temporariamente serviços que não estão sendo oferecidos sem precisar excluí-los do histórico.

4. Especificações Técnicas & Segurança

Recurso Tecnologia / Regra
Backend Framework Python 3.x + Django Web Framework
Segurança de Dados Proteção CSRF ativada, senhas criptografadas pelo Django Auth System
Validação de Horários Constraint única no Banco de Dados (UniqueConstraint) impedindo múltiplos agendamentos ativos na mesma data e horário.
Comunicação Assíncrona Consultas dinâmicas de horários e cancelamentos via Fetch API (AJAX / JSON)
